# Three-Minute Demo Script

**Target duration:** 2:45–2:55. Leave several seconds of upload-safe margin.

## Recording Setup

Prepare these tabs before recording:

1. layered architecture HTML, positioned on the system overview;
2. deployed Alibaba Cloud dashboard;
3. one completed Qwen Cloud run detail;
4. receiver output and run metrics;
5. benchmark evidence table;
6. GitHub repository root showing `LICENSE`.

Hide API keys, usernames, IP details you do not want public, raw prompts containing private data,
and unredacted logs.

## Script And Shot List

### 0:00–0:18 — Hook

**Screen:** Title slide, then the layered HTML architecture overview.

**Narration:**

> Most agent systems bet everything on one context window. EvoMolior takes the opposite approach:
> agents are disposable, but reviewed knowledge, evidence, tools, and failure records persist.

### 0:18–0:42 — What / Who

**Screen:** Architecture left side: operator, objective, Genesis Council.

**Narration:**

> EvoMolior is a Qwen Cloud-powered agent society for research, policy, diligence, and technical
> work where the result must be inspectable. A Genesis Council converts the objective into typed
> roles, sealed tests, progressive-disclosure stages, a Worker Node Atlas, and a separate Grader
> Atlas.

### 0:42–1:12 — Society In Motion

**Screen:** Alibaba-hosted dashboard; show two worker groups, roles, round state, and promoted versus
rejected contributions.

**Narration:**

> Competing societies receive redacted views of the same task. Short-lived Researchers, Builders,
> Critics, Archivists, Outliers, and Perspective Takers claim exact nodes, use role-gated tools,
> communicate, and stage work in isolated persistent substrates. Critic authority promotes or
> rejects that work, so later agents inherit reviewed state rather than raw chat history.

### 1:12–1:38 — Disagreement And Evaluation

**Screen:** Grading or timeline view; exact node scores, stage advancement, capture, or replay.

**Narration:**

> Separate grader societies freeze criteria before evidence is revealed. They evaluate exact node
> bundles in an isolated scoring process. Those results drive capture, rewards, round feedback, and
> what each society is allowed to see next. Disagreement becomes replayable evidence, not an
> invisible prompt rewrite.

### 1:38–2:03 — Qwen Cloud Proof

**Screen:** Run config showing `qwen-cloud` and model assignments; briefly show Qwen implementation
files and, if available, Qwen Cloud usage analytics.

**Narration:**

> Qwen Cloud is a first-class backend. EvoMolior connects directly through DashScope, supports Qwen
> 3.7 Plus and Qwen 3.6 Flash, handles structured output and required function calls, marks long
> repeated context for caching, records token metadata, and can generate final visual assets with
> Qwen Image 2.0 Pro.

### 2:03–2:29 — Result And Audit Trail

**Screen:** Receiver artifact, `run-metrics-v1.json`, replay, and manifest.

**Narration:**

> The final writer does not get a free pass. Its artifact must satisfy the output contract and
> sealed tests inside a bounded retry loop. Publication waits for quiescence and settled
> reservations, then emits the receiver file, explicit available or unavailable metrics, score
> replay, and a hash-verifiable archive.

### 2:29–2:48 — Evidence Without Hype

**Screen:** Compact benchmark table.

**Narration:**

> On two small Qwen Cloud FRAMES comparisons, the society beat a direct Qwen 3.7 Plus agent: two of
> three versus one of three, and one of one versus zero of one on a hard task. Research-synthesis
> comparisons tied and the society was much slower. We measure where society helps—we do not assume
> it.

### 2:48–2:57 — Close

**Screen:** Repository root with architecture, license, and submission links.

**Narration:**

> EvoMolior makes collective intelligence durable, inspectable, and honest. The code is open source
> under AGPL v3.

## Must-Capture Visual Proof

- browser URL or console context demonstrating Alibaba Cloud hosting;
- Qwen Cloud backend/model identity;
- multiple roles or societies;
- final artifact;
- architecture diagram;
- root `LICENSE`;
- benchmark caveat, not only the win.

## Editing Rules

- Keep code shots under four seconds unless highlighting one exact symbol.
- Use 150% browser zoom for metrics and paths.
- Add captions for “Qwen Cloud,” “Agent Society,” and “Alibaba Cloud.”
- Remove pauses before upload; do not speed narration until it becomes difficult to understand.
- Upload early enough for YouTube/Vimeo processing, then verify playback while logged out.
