Deep review · ARC-AGI-3

An online system-identification problem disguised as small games.

Official target: interact with novel environments without instructions, efficiently explore, build predictive models, infer goals, and plan/execute. The metric squares action efficiency, so repeated no-ops and meandering are punished sharply.

Environment

  • Series of levels; state changes synchronously after actions.
  • 64×64 grid; 16 possible colors; transitions may include frame sequences.
  • Five simple key actions, coordinate selection, and optional undo.

RHAE

level = min(1.15, (human_actions / ai_actions)²)

Later levels receive higher weights. Internal reasoning/tool calls do not count as environment actions, but they still consume runtime and memory.

Development loop

  • Python 3.12.
  • Edit only agent/my_agent.py.
  • make play-local then make submit.
  • Local engine is the recommended high-throughput test mode.

Failure modes that should become tests, not prose

F1

True local effect, false world model

The agent notices a change but generalizes the wrong causal rule. Test one-step prediction, counterfactual actions and falsifier retention.

F2

Wrong abstraction from familiar games

The system imports a chess/platformer/menu story instead of describing observable mechanics. Require representation-neutral hypotheses and evidence spans.

F3

Solved the level, did not learn the game

A win does not constrain later policy. Force a post-win consolidation step and measure next-level first-attempt efficiency.

Deep review · ARC-AGI-2

An exact program-induction problem with two chances—and a brutal coverage bottleneck.

Official target: reach 85% on the private evaluation set within Kaggle efficiency limits. Every test input receives exactly two predicted grids; either exact match earns the point. Partial pixel correctness earns nothing in competition scoring.

Data

  • 1,000 public training tasks.
  • 120 public evaluation tasks.
  • Separate semi-private and fully private tiers.
  • Typical task: ~3 demonstrations and 1–2 test inputs.

Why direct prompting is weak

The official guide reports direct LLM prompting below 5%. Stronger lines use discrete program search, DSL synthesis, synthetic augmentation, active/test-time adaptation and ensembles.

Correct unit of search

Not “the final grid” alone. Search over an executable hypothesis that reproduces every demonstration, then apply it to test inputs. Treat any failed train pair as a hard counterexample.

Proposal A · ARC-AGI-3

EvoWorld-3 — Verified Hypothesis Ledger Agent

Thesis: combine the low-cost mechanisms that repeatedly survive public evidence—legal guards, no-op suppression, salience, graph frontiers and compact reflection—with explicit falsifiers and transfer checks that address the official failure modes.

Perception

  • Canonical frame hash and delta.
  • Connected components, color rarity and motion.
  • Separate static layout from controllable entities.

World model

  • State-action graph.
  • Action-effect beta counts.
  • Hypothesis fields: rule, evidence, prediction, falsifier, confidence.

Policy

  • Reversible information gain.
  • Frontier path planning.
  • Goal-progress probes after causal confidence.

Decision hierarchy: invalid/illegal filter → death/reset handling → detect previous effect → update/falsify ledger → exploit known goal path if confident → test highest-value frontier → rare-color coordinate probe → deterministic fallback.

Optional local model: a compact VLM/LLM receives only cropped components, deltas and the ledger when the controller is uncertain. Its output is constrained to legal structured actions and must compete against the symbolic policy in an arbiter ablation.

Drop-in starter: arc3/agent_my_agent.py
"""EvoWorld-3: verified-hypothesis-ledger starter for ARC-AGI-3.

Drop this file into the official ARC-AGI-3 Kaggle Starter as agent/my_agent.py.
It is a compact, offline scaffold—not a claimed competitive solution. The design
combines four public lessons:
  1. obey legal-action constraints and repair invalid plans;
  2. prefer actions/clicks that have produced state changes;
  3. track a directed state-action graph and avoid repeated no-ops; and
  4. preserve a compact causal ledger across levels instead of full transcripts.

The implementation deliberately uses introspection when reading frame grids so it
can fail safely if the framework representation changes. Test it against the live
starter before submission and adapt _extract_grid() to the installed arcengine.
"""
from __future__ import annotations

import math
from collections import Counter, defaultdict
from typing import Any, Iterable

from arcengine import FrameData, GameAction, GameState
from agents.agent import Agent


class MyAgent(Agent):
    MAX_ACTIONS = 140

    def __init__(self, *args: Any, **kwargs: Any) -> None:
        super().__init__(*args, **kwargs)
        self.previous_state: tuple[tuple[int, ...], ...] | None = None
        self.previous_action_key: str | None = None
        self.last_level_count = 0
        self.noop_streak = 0
        self.state_visits: Counter[tuple[tuple[int, ...], ...]] = Counter()
        self.state_action_trials: Counter[tuple[tuple[tuple[int, ...], ...], str]] = Counter()
        self.action_changes: Counter[str] = Counter()
        self.action_trials: Counter[str] = Counter()
        self.clicked_signatures: Counter[tuple[int, int, int]] = Counter()
        self.level_summaries: list[dict[str, Any]] = []
        self.step_index = 0

    @property
    def name(self) -> str:
        return f'{super().name}.evoworld3-ledger-v0.{self.MAX_ACTIONS}'

    def is_done(self, frames: list[FrameData], latest_frame: FrameData) -> bool:
        return latest_frame.state is GameState.WIN

    @staticmethod
    def _as_grid(value: Any) -> tuple[tuple[int, ...], ...] | None:
        if hasattr(value, 'tolist'):
            value = value.tolist()
        if isinstance(value, dict):
            for key in ('frame', 'grid', 'observation', 'pixels', 'data'):
                if key in value:
                    result = MyAgent._as_grid(value[key])
                    if result is not None:
                        return result
            return None
        if not isinstance(value, (list, tuple)) or not value:
            return None
        rows = []
        for row in value:
            if hasattr(row, 'tolist'):
                row = row.tolist()
            if not isinstance(row, (list, tuple)) or not row:
                return None
            try:
                rows.append(tuple(int(x) for x in row))
            except (TypeError, ValueError):
                return None
        if len({len(row) for row in rows}) != 1:
            return None
        return tuple(rows)

    @classmethod
    def _extract_grid(cls, latest_frame: FrameData) -> tuple[tuple[int, ...], ...] | None:
        for attr in ('frame', 'grid', 'observation', 'pixels', 'data'):
            if hasattr(latest_frame, attr):
                result = cls._as_grid(getattr(latest_frame, attr))
                if result is not None:
                    return result
        try:
            if hasattr(latest_frame, 'model_dump'):
                return cls._as_grid(latest_frame.model_dump())
        except Exception:
            pass
        return None

    @staticmethod
    def _difference(a: tuple[tuple[int, ...], ...] | None,
                    b: tuple[tuple[int, ...], ...] | None) -> int:
        if a is None or b is None or len(a) != len(b) or len(a[0]) != len(b[0]):
            return int(a != b)
        return sum(x != y for ra, rb in zip(a, b) for x, y in zip(ra, rb))

    @staticmethod
    def _action_key(action: GameAction) -> str:
        return getattr(action, 'name', None) or str(getattr(action, 'value', action))

    @staticmethod
    def _legal_actions(latest_frame: FrameData) -> list[GameAction]:
        raw = getattr(latest_frame, 'available_actions', None)
        legal: list[GameAction] = []
        if raw:
            for value in raw:
                if isinstance(value, GameAction):
                    legal.append(value)
                    continue
                for action in GameAction:
                    if value in (getattr(action, 'name', None), getattr(action, 'value', None), str(action)):
                        legal.append(action)
                        break
        if not legal:
            legal = [action for action in GameAction if action is not GameAction.RESET]
        # Preserve order while deduplicating enum values.
        seen = set()
        result = []
        for action in legal:
            key = MyAgent._action_key(action)
            if key not in seen and action is not GameAction.RESET:
                result.append(action)
                seen.add(key)
        return result

    def _record_transition(self, state: tuple[tuple[int, ...], ...] | None) -> None:
        if self.previous_state is None or self.previous_action_key is None:
            return
        changed = self._difference(self.previous_state, state) > 0
        self.action_trials[self.previous_action_key] += 1
        if changed:
            self.action_changes[self.previous_action_key] += 1
            self.noop_streak = 0
        else:
            self.noop_streak += 1

    def _consolidate_level(self, levels_completed: int) -> None:
        if levels_completed <= self.last_level_count:
            return
        best_actions = sorted(
            self.action_trials,
            key=lambda key: (self.action_changes[key] / max(1, self.action_trials[key]), self.action_changes[key]),
            reverse=True,
        )[:4]
        self.level_summaries.append({
            'level': levels_completed,
            'high_effect_actions': best_actions,
            'states_seen': len(self.state_visits),
            'no_op_streak_at_win': self.noop_streak,
        })
        # Preserve global action-effect priors, but clear level-specific graph state.
        self.state_visits.clear()
        self.state_action_trials.clear()
        self.clicked_signatures.clear()
        self.previous_state = None
        self.previous_action_key = None
        self.noop_streak = 0
        self.last_level_count = levels_completed

    def _rare_click(self, grid: tuple[tuple[int, ...], ...], action: GameAction) -> GameAction:
        counts = Counter(value for row in grid for value in row)
        candidates = []
        for r, row in enumerate(grid):
            for c, color in enumerate(row):
                if color == 0:
                    continue
                signature = (r, c, color)
                # Rare colors and never-tried coordinates are information-rich.
                score = 4.0 / max(1, counts[color])
                score += 2.0 / (1 + self.clicked_signatures[signature])
                # Mild center preference avoids repeatedly clicking borders/background frames.
                center_r, center_c = (len(grid) - 1) / 2, (len(row) - 1) / 2
                distance = abs(r - center_r) + abs(c - center_c)
                score += 0.1 / (1 + distance)
                candidates.append((score, -r, -c, r, c, color))
        if candidates:
            _, _, _, r, c, color = max(candidates)
        else:
            r = len(grid) // 2
            c = len(grid[0]) // 2
            color = grid[r][c]
        self.clicked_signatures[(r, c, color)] += 1
        action.set_data({'x': int(c), 'y': int(r)})
        action.reasoning = {
            'policy': 'rare-color information probe',
            'coordinate': [int(c), int(r)],
            'color': int(color),
            'noop_streak': self.noop_streak,
        }
        return action

    def _simple_action_score(self, state: tuple[tuple[int, ...], ...], action: GameAction) -> float:
        key = self._action_key(action)
        local_trials = self.state_action_trials[(state, key)]
        global_trials = self.action_trials[key]
        global_effect = self.action_changes[key] / max(1, global_trials)
        novelty = 3.0 / (1 + local_trials)
        learned_effect = 1.5 * global_effect
        exploration_bonus = 0.35 / math.sqrt(1 + global_trials)
        undo = getattr(GameAction, 'ACTION7', None)
        undo_penalty = -1.0 if undo is not None and action is undo and self.noop_streak < 3 else 0.0
        return novelty + learned_effect + exploration_bonus + undo_penalty

    def choose_action(self, frames: list[FrameData], latest_frame: FrameData) -> GameAction:
        self.step_index += 1
        if latest_frame.state in (GameState.NOT_PLAYED, GameState.GAME_OVER):
            self.previous_state = None
            self.previous_action_key = None
            action = GameAction.RESET
            action.reasoning = 'reset initial/dead state'
            return action

        levels_completed = int(getattr(latest_frame, 'levels_completed', 0) or 0)
        self._consolidate_level(levels_completed)
        state = self._extract_grid(latest_frame)
        self._record_transition(state)

        legal = self._legal_actions(latest_frame)
        if not legal:
            action = GameAction.RESET
            action.reasoning = 'no legal actions exposed; safe reset'
            return action

        if state is None:
            # Framework shape changed: remain valid and deterministic rather than crash.
            action = min(legal, key=self._action_key)
            if action.is_complex():
                action.set_data({'x': 32, 'y': 32})
            action.reasoning = 'frame grid unavailable; deterministic legal fallback'
            self.previous_action_key = self._action_key(action)
            return action

        self.state_visits[state] += 1
        complex_actions = [action for action in legal if action.is_complex()]
        simple_actions = [action for action in legal if not action.is_complex()]

        # Use coordinate selection early, after repeated no-ops, or when simple actions
        # have already been tested from this state.
        all_simple_tested = simple_actions and all(
            self.state_action_trials[(state, self._action_key(action))] > 0 for action in simple_actions
        )
        if complex_actions and (self.step_index <= 2 or self.noop_streak >= 2 or all_simple_tested):
            action = self._rare_click(state, complex_actions[0])
        elif simple_actions:
            action = max(simple_actions, key=lambda a: (self._simple_action_score(state, a), self._action_key(a)))
            action.reasoning = {
                'policy': 'state-action frontier',
                'state_visits': self.state_visits[state],
                'local_trials': self.state_action_trials[(state, self._action_key(action))],
                'global_effect_rate': self.action_changes[self._action_key(action)] / max(1, self.action_trials[self._action_key(action)]),
                'noop_streak': self.noop_streak,
                'levels_remembered': len(self.level_summaries),
            }
        else:
            action = self._rare_click(state, complex_actions[0])

        key = self._action_key(action)
        self.state_action_trials[(state, key)] += 1
        self.previous_state = state
        self.previous_action_key = key
        return action
Proposal B · ARC-AGI-2

EvoARC-2 — Diverse Program Portfolio with Equivariant Two-Guess Selection

Thesis: turn EvoMolior’s competing groups into genuinely independent candidate generators, then use exact train execution and structural diversity—not persuasive reasoning—to select two outputs.

Candidate families

  • Typed object/geometry DSL.
  • Pixel/dihedral/color programs.
  • Native 2D neural/TTT branch.
  • Code or textual hypothesis branch, offline only.

Hard gates

  • Exact every demonstration.
  • Output shape/color validity.
  • Equivariance under task-consistent transforms.
  • Runtime and memory cap.

Ranking

  • Minimum description length.
  • Mutation stability.
  • Family calibration.
  • Attempt-2 marginal diversity.

Routing rule: before expanding search, test whether the DSL has any valid first transition. Zero-step coverage failures move to neural/code/object alternatives. Structurally doomed trajectories stop early and return budget to hard but viable tasks.

from pathlib import Path
from typing import Callable, Iterable, Sequence

Grid = list[list[int]]
Transform = Callable[[Grid], Grid]


def is_grid(value: object) -> bool:
    if not isinstance(value, list) or not value or not all(isinstance(row, list) for row in value):
        return False
    widths = {len(row) for row in value}
    if len(widths) != 1 or 0 in widths or len(value) > 30 or next(iter(widths)) > 30:
        return False
    return all(isinstance(x, int) and 0 <= x <= 9 for row in value for x in row)


def exact(a: Grid, b: Grid) -> bool:
    return a == b


def pixel_score(a: Grid, b: Grid) -> float:
    if not is_grid(a) or not is_grid(b) or len(a) != len(b) or len(a[0]) != len(b[0]):
        return 0.0
    total = len(a) * len(a[0])
    return sum(x == y for ra, rb in zip(a, b) for x, y in zip(ra, rb)) / total


def identity(g: Grid) -> Grid:
    return copy.deepcopy(g)


def hflip(g: Grid) -> Grid:
    return [list(reversed(row)) for row in g]


def vflip(g: Grid) -> Grid:
    return list(reversed(copy.deepcopy(g)))


def rot90(g: Grid) -> Grid:
    return [list(row) for row in zip(*reversed(g))]


def rot180(g: Grid) -> Grid:
    return rot90(rot90(g))


def rot270(g: Grid) -> Grid:
    return rot90(rot180(g))


def transpose(g: Grid) -> Grid:
    return [list(row) for row in zip(*g)]


def crop_bbox(g: Grid) -> Grid:
    cells = [(r, c) for r, row in enumerate(g) for c, value in enumerate(row) if value != 0]
    if not cells:
        return [[0]]
    r0, r1 = min(r for r, _ in cells), max(r for r, _ in cells)
    c0, c1 = min(c for _, c in cells), max(c for _, c in cells)
    return [row[c0:c1 + 1] for row in g[r0:r1 + 1]]


def crop_right_of_separator(g: Grid) -> Grid:
    h, w = len(g), len(g[0])
    candidates = []
    for c in range(w - 1):
        col = [g[r][c] for r in range(h)]
        if len(set(col)) == 1 and col[0] != 0:
            candidates.append(c)
    if not candidates:
        raise ValueError('no separator column')
    c = candidates[-1]
    out = [row[c + 1:] for row in g]
    if not is_grid(out):
        raise ValueError('empty crop')
    return out


def infer_color_map(train: Sequence[dict]) -> dict[int, int] | None:
    mapping: dict[int, int] = {}
    for pair in train:
        inp, out = pair['input'], pair['output']
        if len(inp) != len(out) or len(inp[0]) != len(out[0]):
            return None
        for a, b in zip((x for row in inp for x in row), (x for row in out for x in row)):
            if a in mapping and mapping[a] != b:
                return None
            mapping[a] = b
    return mapping


def contextual_symbolic_relay(g: Grid) -> Grid:
    """Solve the original holdout family included with this pack.

    Layout: a 4-column legend, one constant separator column, then a workspace.
    The two colored legend markers encode a displacement vector. The marker color
    present in the workspace is the source; the other is the target. Move the
    source object by the vector, recolor it to the target, crop the legend, and
    preserve unrelated objects.
    """
    h, w = len(g), len(g[0])
    if w < 7:
        raise ValueError('too narrow')
    sep = None
    for c in range(1, w - 1):
        col = [g[r][c] for r in range(h)]
        if len(set(col)) == 1 and col[0] != 0:
            sep = c
            break
    if sep is None or sep < 2:
        raise ValueError('separator not found')
    legend = [row[:sep] for row in g]
    workspace = [row[sep + 1:] for row in g]
    markers = [(r, c, legend[r][c]) for r in range(h) for c in range(sep) if legend[r][c] != 0]
    by_color: dict[int, list[tuple[int, int]]] = {}
    for r, c, color in markers:
        by_color.setdefault(color, []).append((r, c))
    if len(by_color) != 2 or any(len(v) != 1 for v in by_color.values()):
        raise ValueError('expected exactly two unique legend markers')
    counts = Counter(value for row in workspace for value in row)
    colors = list(by_color)
    present = [color for color in colors if counts[color] > 0]
    if len(present) != 1:
        raise ValueError('source color is ambiguous')
    source = present[0]
    target = colors[0] if colors[1] == source else colors[1]
    sr, sc = by_color[source][0]
    tr, tc = by_color[target][0]
    dy, dx = tr - sr, tc - sc
    source_cells = [(r, c) for r, row in enumerate(workspace) for c, value in enumerate(row) if value == source]
    if not source_cells:
        raise ValueError('source object absent')
    out = copy.deepcopy(workspace)
    for r, c in source_cells:
        out[r][c] = 0
    for r, c in source_cells:
        nr, nc = r + dy, c + dx
        if not (0 <= nr < len(out) and 0 <= nc < len(out[0])):
            raise ValueError('displacement exits grid')
        out[nr][nc] = target
    return out


@dataclass(frozen=True)
class Program:
    name: str
    family: str
    complexity: int
    fn: Transform

    def apply(self, grid: Grid) -> Grid:
        out = self.fn(copy.deepcopy(grid))
        if not is_grid(out):
            raise ValueError(f'{self.name} produced an invalid grid')
        return out


def candidate_programs(task: dict) -> list[Program]:
    programs = [
        Program('identity', 'geometric', 1, identity),
        Program('hflip', 'geometric', 2, hflip),
        Program('vflip', 'geometric', 2, vflip),
        Program('rot90', 'geometric', 2, rot90),
        Program('rot180', 'geometric', 2, rot180),
        Program('rot270', 'geometric', 2, rot270),
        Program('transpose', 'geometric', 2, transpose),
        Program('crop_bbox', 'object', 3, crop_bbox),
        Program('crop_right_of_separator', 'layout', 3, crop_right_of_separator),
        Program('contextual_symbolic_relay', 'relational', 6, contextual_symbolic_relay),
    ]
    train = task.get('train', [])
    if train and all(pair.get('output') == train[0].get('output') for pair in train):
        constant = copy.deepcopy(train[0]['output'])
        programs.append(Program('constant_output', 'memorized-shape', 5, lambda _g, x=constant: copy.deepcopy(x)))
    mapping = infer_color_map(train)
    if mapping is not None:
        programs.append(Program(
            'global_color_map', 'color', 3,
            lambda g, m=mapping: [[m.get(value, value) for value in row] for row in g],
        ))
    return programs


def score_program(program: Program, train: Sequence[dict]) -> tuple[int, float]:
    exact_count = 0
    pixels = 0.0
    for pair in train:
        try:
            prediction = program.apply(pair['input'])
        except Exception:
            return -1, -1.0
        exact_count += int(exact(prediction, pair['output']))
        pixels += pixel_score(prediction, pair['output'])
    return exact_count, pixels / max(1, len(train))


def ranked_programs(task: dict) -> list[Program]:
    train = task.get('train', [])
    scored = []
    for program in candidate_programs(task):
        exact_count, pixels = score_program(program, train)
        if exact_count >= 0:
            scored.append((exact_count, pixels, -program.complexity, program.name, program))
    scored.sort(reverse=True, key=lambda item: item[:4])
    return [item[-1] for item in scored]


def fallback_outputs(inp: Grid) -> list[Grid]:
    outputs = [identity(inp)]
    try:
        outputs.append(crop_bbox(inp))
    except Exception:
        pass
    zero = [[0 for _ in row] for row in inp]
    outputs.append(zero)
    return outputs


def select_two_outputs(task: dict, test_input: Grid) -> tuple[Grid, Grid, list[str]]:
    train_len = len(task.get('train', []))
    candidates: list[tuple[Grid, Program, bool]] = []
    for program in ranked_programs(task):
        exact_count, _ = score_program(program, task.get('train', []))
        try:
            out = program.apply(test_input)
        except Exception:
            continue
        candidates.append((out, program, exact_count == train_len))

    chosen: list[tuple[Grid, str, str]] = []
    # First: simplest exact program, otherwise best approximate program.
    for out, program, is_exact in candidates:
        if is_exact:
            chosen.append((out, program.name, program.family))
            break
    if not chosen and candidates:
        out, program, _ = candidates[0]
        chosen.append((out, program.name, program.family))

    # Second: prefer an exact program from a different family and a different output.
    for out, program, is_exact in candidates:
        if chosen and out == chosen[0][0]:
            continue
        if is_exact and (not chosen or program.family != chosen[0][2]):
            chosen.append((out, program.name, program.family))
            break
    # Then any distinct candidate.
    if len(chosen) < 2:
        for out, program, _ in candidates:
            if all(out != existing[0] for existing in chosen):
                chosen.append((out, program.name, program.family))
                break
    # Finally deterministic fallbacks.
    if len(chosen) < 2:
        for index, out in enumerate(fallback_outputs(test_input)):
            if all(out != existing[0] for existing in chosen):
                chosen.append((out, f'fallback_{index}', 'fallback'))
            if len(chosen) == 2:
                break
    if len(chosen) == 1:
        chosen.append((copy.deepcopy(chosen[0][0]), 'duplicate_last_resort', 'fallback'))
    if not chosen:
        zero = [[0 for _ in row] for row in test_input]
        chosen = [(zero, 'zero', 'fallback'), (copy.deepcopy(zero), 'zero_duplicate', 'fallback')]
    return chosen[0][0], chosen[1][0], [chosen[0][1], chosen[1][1]]


def build_submission(challenges: dict) -> tuple[dict, dict]:
    submission: dict = {}
    provenance: dict = {}
    for task_id, task in challenges.items():
        task_predictions = []
        task_provenance = []
        for test_pair in task.get('test', []):
            attempt_1, attempt_2, names = select_two_outputs(task, test_pair['input'])
            task_predictions.append({'attempt_1': attempt_1, 'attempt_2': attempt_2})
            task_provenance.append({'attempt_1_program': names[0], 'attempt_2_program': names[1]})
        submission[task_id] = task_predictions
        provenance[task_id] = task_provenance
    validate_submission(challenges, submission)
    return submission, provenance


def validate_submission(challenges: dict, submission: dict) -> None:
    if set(challenges) != set(submission):
        missing = set(challenges) - set(submission)
        extra = set(submission) - set(challenges)
        raise ValueError(f'task key mismatch: missing={missing}, extra={extra}')
    for task_id, task in challenges.items():
        rows = submission[task_id]
        if not isinstance(rows, list) or len(rows) != len(task.get('test', [])):
            raise ValueError(f'{task_id}: expected one submission row per test input')
        for index, row in enumerate(rows):
            if set(row) != {'attempt_1', 'attempt_2'}:
                raise ValueError(f'{task_id}[{index}]: expected exactly attempt_1/attempt_2')
            for key in ('attempt_1', 'attempt_2'):
                if not is_grid(row[key]):
                    raise ValueError(f'{task_id}[{index}].{key}: invalid grid')


def find_first(patterns: Iterable[str]) -> str | None:
    for pattern in patterns:
        hits = sorted(glob.glob(pattern, recursive=True))
        if hits:
            return hits[0]
    return None


def locate_competition_file() -> str:
    explicit = os.environ.get('ARC_AGI2_CHALLENGES')
    if explicit:
        return explicit
    patterns = [
        '/kaggle/input/arc-prize-2026-arc-agi-2/arc-agi_evaluation_challenges.json',
        '/kaggle/input/competitions/arc-prize-2026-arc-agi-2/arc-agi_evaluation_challenges.json',
        '/kaggle/input/**/arc-agi_evaluation_challenges.json',
    ]
    path = find_first(patterns)
    if not path:
        raise FileNotFoundError('Could not find arc-agi_evaluation_challenges.json; set ARC_AGI2_CHALLENGES.')
    return path


def score_against_solution(submission: dict, solution: dict) -> tuple[int, int]:
    solved = 0
    total = 0
    for task_id, rows in solution.items():
        for i, expected_row in enumerate(rows):
            expected = expected_row['output']
            pred = submission[task_id][i]
            solved += int(pred['attempt_1'] == expected or pred['attempt_2'] == expected)
            total += 1
    return solved, total


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument('--challenge', help='Challenge JSON; defaults to Kaggle competition input.')
    parser.add_argument('--solution', help='Optional local solution JSON for scoring.')
    parser.add_argument('--output', default='/kaggle/working/submission.json')

    challenge_path = args.challenge or locate_competition_file()
    challenges = json.loads(Path(challenge_path).read_text())

        solution = json.loads(Path(args.solution).read_text())
        solved, total = score_against_solution(submission, solution)

#!/usr/bin/env python3
"""Standalone evaluator for the original Switch–Lock Relay holdout.

This simulator is intentionally independent of ARC Prize game files. It lets an
EvoMolior research run test causal memory, transfer and action efficiency without
reading or tuning on official evaluation environments.
"""
from __future__ import annotations

import argparse
import json
from collections import deque
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable

MOVE = {1: (-1, 0), 2: (1, 0), 3: (0, -1), 4: (0, 1)}
KEYS = {'a', 'b', 'r'}
DOORS = {'A': 'a', 'B': 'b', 'R': 'r'}


@dataclass(frozen=True)
class State:
    row: int
    col: int
    inventory: str | None
    removed_keys: frozenset[tuple[int, int]]
    won: bool = False


class SwitchLockLevel:
    def __init__(self, spec: dict):
        self.id = spec['id']
        self.grid = spec['grid']
        widths = {len(row) for row in self.grid}
        if len(widths) != 1:
            raise ValueError(f'{self.id}: ragged grid')
        starts = [(r, c) for r, row in enumerate(self.grid) for c, value in enumerate(row) if value == 'P']
        if len(starts) != 1:
            raise ValueError(f'{self.id}: expected one P')
        self.start = State(*starts[0], None, frozenset(), False)

    def tile(self, state: State, row: int, col: int) -> str:
        value = self.grid[row][col]
        if (row, col) in state.removed_keys and value in KEYS:
            return '.'
        return value

    def step(self, state: State, action: int) -> State:
        if state.won:
            return state
        if action == 5:
            return State(state.row, state.col, None, state.removed_keys, False)
        if action not in MOVE:
            return state
        dr, dc = MOVE[action]
        nr, nc = state.row + dr, state.col + dc
        if not (0 <= nr < len(self.grid) and 0 <= nc < len(self.grid[0])):
            return state
        target = self.tile(state, nr, nc)
        if target == '#':
            return state
        if target in DOORS and state.inventory != DOORS[target]:
            return state

        inventory = state.inventory
        removed = set(state.removed_keys)
        if target in DOORS:
            inventory = None
        elif target in KEYS and (nr, nc) not in removed and inventory is None:
            inventory = target
            removed.add((nr, nc))
        elif target == 'C' and inventory == 'a':
            inventory = 'b'
        won = target == 'G'
        return State(nr, nc, inventory, frozenset(removed), won)

    def render(self, state: State) -> str:
        rows = [list(row) for row in self.grid]
        for r, c in state.removed_keys:
            if rows[r][c] in KEYS:
                rows[r][c] = '.'
        rows[state.row][state.col] = 'P'
        return '\n'.join(''.join(row) for row in rows) + f'\ninventory={state.inventory!r} won={state.won}'


def shortest_path(level: SwitchLockLevel, max_nodes: int = 100_000) -> list[int]:
    queue = deque([(level.start, [])])
    seen = {level.start}
    while queue:
        state, path = queue.popleft()
        if state.won:
            return path
        for action in (1, 2, 3, 4, 5):
            nxt = level.step(state, action)
            if nxt not in seen:
                seen.add(nxt)
                queue.append((nxt, path + [action]))
                if len(seen) > max_nodes:
                    raise RuntimeError('state-space cap exceeded')
    raise RuntimeError(f'{level.id}: no solution')


def replay(level: SwitchLockLevel, actions: Iterable[int]) -> State:
    state = level.start
    for action in actions:
        state = level.step(state, int(action))
    return state


def level_score(human_actions: int, agent_actions: int, won: bool) -> float:
    if not won or agent_actions <= 0:
        return 0.0
    return min(1.15, (human_actions / agent_actions) ** 2)


def weighted_game_score(scores: list[float]) -> float:
    weights = list(range(1, len(scores) + 1))
    return sum(w * s for w, s in zip(weights, scores)) / sum(weights)


def validate_file(path: str) -> list[SwitchLockLevel]:
    data = json.loads(Path(path).read_text())
    levels = [SwitchLockLevel(spec) for spec in data['levels']]
    for level in levels:
        path_actions = shortest_path(level)
        final = replay(level, path_actions)
        if not final.won:
            raise AssertionError(f'{level.id}: BFS replay did not win')
    return levels


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument('spec', nargs='?', default=str(Path(__file__).with_name('arc3_switch_lock_relay.json')))
    parser.add_argument('--actions', help='Comma-separated action list to replay on each level.')
    args = parser.parse_args()
    levels = validate_file(args.spec)
    print('Switch–Lock Relay validation')
    scores = []
    for level in levels:
        optimum = shortest_path(level)
        print(f'{level.id}: optimal actions={len(optimum)} path={optimum}')
        if args.actions:
            agent_actions = [int(x) for x in args.actions.split(',') if x.strip()]
            won = replay(level, agent_actions).won
            score = level_score(len(optimum), len(agent_actions), won)
            scores.append(score)
            print(f'  supplied actions: won={won}, level_score={score:.4f}')
        else:
            scores.append(1.0)
    print(f'weighted score (oracle paths): {weighted_game_score(scores):.4f}')


if __name__ == '__main__':
    main()

# EvoMolior ARC Prize 2026 research-system prompt

You are an evidence-first research and experiment society working on ARC-AGI-2 and ARC-AGI-3.
Your job is not to produce persuasive prose. Your job is to reduce uncertainty, create executable
artifacts, and preserve a provenance trail that another engineer can reproduce offline.

## Non-negotiable constraints

1. Label every substantive item as one of:
   - `[O]` official rule/data/tooling source;
   - `[K]` Kaggle notebook, leaderboard or discussion;
   - `[P]` research paper;
   - `[C]` community repository/write-up;
   - `[E]` our controlled experiment;
   - `[I]` inference or design proposal.
2. Never upgrade a public leaderboard result, a public-game score, or an author-reported paper
   result into evidence of private-set generalization.
3. Never inspect or hand-tune against the public ARC-AGI-2 evaluation tasks. Treat them as sealed.
4. Track licenses for every imported code path, model, weight file and dataset. The competition
   requires reproducible open-source solutions; do not assume a Kaggle notebook is reusable.
5. Kaggle evaluation has no internet. Research may be distributed and agentic before packaging;
   the final solver must be self-contained, deterministic enough to debug, and resource bounded.
6. Every proposed component needs: hypothesis, baseline, treatment, metric, budget, stop rule,
   failure modes and ablation. Reject architectural ornament with no measurable contribution.
7. Preserve negative results and dead ends. A rejected method must include the exact evidence that
   caused rejection so later agents do not repeat it.
8. Produce files, not merely chat summaries. Required run outputs:
   evidence.jsonl, claims.md, experiments.jsonl, ablations.csv, license_ledger.csv,
   failure_clusters.md, implementation_plan.md, and a compact submission artifact.

## Shared research questions

- What does the official metric actually reward, and which proxy metrics are misleading?
- Which public solution mechanisms survive ablation, and which merely co-occur with a score?
- Where does the current solver fail because its representation/DSL lacks coverage rather than
  because its search budget is too small?
- How can two guesses (ARC-AGI-2) or exploratory actions (ARC-AGI-3) be selected to maximize
  complementary information rather than correlated repetition?
- Which expensive research-time discoveries can be distilled into a cheap offline runtime?

## Handoff protocol

Each role writes a structured handoff with:

```json
{

  "claims_disputed": [],
  "artifacts_created": [],
  "tests_run": [],
  "failures": [],
  "next_questions": [],
  "budget_used": {},

```

A Critic may promote a claim to `verified` only when it has direct source support or a reproducible
experiment. An Integrator may merge code only when unit tests, an offline smoke test and a license
entry exist. A Grader scores generalization evidence, not narrative sophistication.

  1. Locate the live challenge and sample files robustly; do not hard-code one path without fallback.

  3. Each entry has exactly attempt_1 and attempt_2.
  4. Every output is a non-empty rectangular integer grid, values 0–9, allowed dimensions.

What this package does not claim

Honest limits

No hidden evaluation data was available. The generated code has not received a Kaggle leaderboard score. It is a validated implementation scaffold and research plan, not a promise of prize-level performance.
  • The ARC-AGI-3 frame extraction uses defensive introspection and must be adapted/tested against the current installed arcengine representation.
  • The ARC-AGI-2 portfolio is deliberately small; its purpose is to establish a correct executable/validation architecture that EvoMolior can expand.
  • Public notebook code was surveyed for mechanisms and operational lessons; it was not copied into the starter. License review is still mandatory before importing any third-party implementation.
  • Leaderboard values, hardware options and rules can change. The live Kaggle pages remain authoritative.
  • The supplied project file describes EvoKammer conceptually; no source tree was examined, so the exact effort to integrate these prompts/schemas is unknown.
