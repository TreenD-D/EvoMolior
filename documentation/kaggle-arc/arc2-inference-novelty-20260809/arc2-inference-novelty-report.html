3. Plateau and causal diagnosis

Finite retrieval and prompt ceiling

Observed: the compact codec removed most prompt truncation, but this only establishes an input-boundary condition. A 5/18 retrieval result at step 200 shows that a compliant prompt can still retrieve the wrong finite pool. The ceiling is therefore not solely context length: it includes which parents enter the context, how they are ranked, and which edits are expressible.

Verified-real versus synthetic

Observed: synthetic combined coverage stayed exactly 25/96 at every checkpoint, and novel synthetic candidates added zero tasks. Real loss was best at step 50 (0.695853) and rose to 0.934792 by step 200 while synthetic loss rose from 1.276873 to 1.686116. Inferred: synthetic abundance is not evidence of transfer. The next dataset test must preserve provenance strata and report real and synthetic results separately.

What the negative mining history implies

Inferred: repeated failures of bounded hand-designed mining lower the probability that another broad singleton list will reveal the missing mass. Remaining tasks may require relational structure, latent object decomposition, composition, or a better routing policy. The one color-argument mutation is a clue, not a general result; prepend/append aliases, D8, and numeric edits produced no useful incremental real yield in the V2 trajectory.

4. Falsifiable hypothesis portfolio

Filter by novelty class or search by mechanism. “Observed” evidence is source-linked; “Inferred” and “Speculative” entries are explicitly proposals.

H1 · Parent-union recovery extension

Mechanism: union up to seven archived parents by rank plus provenance diversity, preserving complementary programs without checkpoint ensembling. Evidence: V2 swapped one V3 task while total stayed 6/18 (reports/arc2-program-prior-v2-full-20260810.md). Slice: deterministic selector, 63 candidates, target-free freeze. Metric/budget: real retrieval and calls/task; one CPU day. Falsifier: V3 task remains absent with no efficiency gain. Kill/promotion: kill at no recovery; promote to 12-task diagnostic if non-inferior retrieval and ≥2 incremental tasks. Value: separates parent-selection from learning.

H2 · Operation-conditioned edits novel

Mechanism: allocate mutations according to parent AST argument types and residual signatures, prioritizing color/enum edits. Evidence: color mutation produced a5313dff; enum was demo-exact but not target-exact; D8/numeric edits yielded zero incremental tasks. Slice: typed edit policy with held-out scoring. Metric/budget: novel exact precision, ≤63 candidates, 1,000 verifier calls. Falsifier: precision no better than uniform edits. Gates: kill below baseline; promote if ≥2 real incremental tasks without call inflation. Value: tests whether the clue is causal or anecdotal.

H3 · Anti-unified parent schemas novel

Mechanism: anti-unify demonstration-exact programs into a typed schema, then instantiate only fields supported by training pairs. Evidence: demonstration-exact but target-inexact aliases show surface agreement is insufficient. Slice: schema extractor plus exact verifier. Metric/budget: target-free program validity and real exact yield; 2,000 calls. Falsifier: no lift over direct mutation. Gates: kill if schema leakage or invalid-rate rises; promote if two new exact tasks. Value: probes abstraction versus memorization.

H4 · Residual relational signatures novel

Mechanism: represent exact near-miss residuals as object adjacency, symmetry, connectivity, and role relations; route repair operators to the residual class. Evidence: supplied residual-atlas and relational-slice records motivate structure, while bounded mining was weak. Slice: deterministic residual encoder on public training only. Metric/budget: repair lift per verifier call; 1 CPU day. Falsifier: residual classes do not predict repair success. Gates: kill below shuffled-label control; promote only with leakage audit and causal lift. Value: tests representation bottleneck.

H5 · Counterexample-directed repair novel

Mechanism: use the smallest verified disagreement to choose one typed repair, rather than regenerating full programs. Evidence: exact verifier traces exist, but V2 spent 597 calls for six real tasks. Slice: repair loop capped at two edits. Metric/budget: exact yield/call and repair depth; 2,000 calls. Falsifier: no call reduction at matched yield. Gates: kill if repairs change already-correct cells or violate exactness; promote if ≥25% call reduction. Value: directly attacks verifier economics.

H6 · Lossless typed codec extension

Mechanism: retain explicit dimensions, colors, object boundaries, and operator argument types while staying within prompt limits. Evidence: V2 prompt audit passed but 28/800 real training contexts truncated. Slice: round-trip codec tests and token accounting. Metric/budget: zero semantic round-trip loss; CPU only. Falsifier: collision or truncation persists. Gates: kill on any target leakage; promote as infrastructure only, not solver evidence. Value: isolates codec from model.

H7 · Information-gain router novel

Mechanism: route tasks to niches by expected verifier information gain, uncertainty, and residual class, preserving minority specialists. Evidence: equal coverage with 4.15× worse efficiency suggests allocation failure. Slice: logged router versus scalar ranker. Metric/budget: yield/call and niche coverage; 3,000 calls. Falsifier: random or scalar routing matches. Gates: kill if one niche monopolizes budget; promote if Pareto-improves yield and diversity. Value: tests search economics.

H8 · Correlation-aware attempt two novel

Mechanism: score attempt 2 by marginal causal coverage, not confidence: penalize shared AST ancestry, residual signature, and failure mode. Evidence: V2/V3 overlap heavily and only swap one task. Slice: pair selector with ancestry hashes. Metric/budget: pass@2 union and pair correlation; 1,000 calls. Falsifier: confidence top-2 is equal or better. Gates: kill if diversity lowers union; promote if union rises without invalid outputs. Value: directly targets contract utility.

H9 · Bounded typed composition novel

Mechanism: compose two independently verified transformations only when interface types and dimensions match. Evidence: typed composition is an explicit required lens; singleton mining has plateaued. Slice: depth-two composer with fail-closed shape checks. Metric/budget: incremental real exact tasks per 1,000 calls. Falsifier: zero novel exact yield or invalid explosion. Gates: kill at <1 task/1,000; promote at ≥2 with no leakage. Value: tests compositional candidate space.

6. Kaggle-safe architecture and integration sequence

  1. Freeze model lineage: pin base model revision, adapter hash, source tree, launcher, package manifest, and configuration. The V2 record gives concrete hashes; every new candidate receives a new content address.
  2. Build local-only package: vendor only approved files, disable network, set deterministic seeds, record Python/runtime configuration, and verify the manifest before loading weights.
  3. Separate roles: model proposes typed programs; deterministic codec validates syntax and round-trips; exact verifier is authoritative on demonstrations; orchestration freezes candidates before any scoring.
  4. Enforce the output contract: for every test input emit exactly two outputs, ordered and shape-valid. If a candidate is invalid, fail closed to a deterministic valid fallback or a clearly logged rejected candidate; never fabricate a score.
  5. Seal evaluation: keep public/hidden test labels and derived targets outside training, generation, routing, and selection. Write provenance and hashes before any sealed evaluation.
  6. Promotion ladder: CPU unit tests → public-training leakage audit → frozen held-out diagnostics → package audit → offline rehearsal → operator review. A pass at an earlier gate is not authorization for a later gate.

Critical separation: the independently recomputed V2 candidates matched exactly, but that validates reproducibility of a failed diagnostic; it does not promote the adapter or authorize public evaluation.

7. Pass@2 as marginal causal coverage

Attempt 2 should maximize the probability that the pair covers a different correct mechanism. For candidate pair (a,b), use a constrained objective such as exact-demo validity plus marginal coverage minus penalties for shared ancestry, same residual signature, same operator family, and correlated failure traces. Confidence remains a tie-breaker, not the primary objective.

Diversity controls

Hash AST ancestry; bucket by codec, operator family, object/relation abstraction, and residual class; cap each bucket; require one candidate from a distinct causal niche when valid.

Correlation controls

Measure identical intermediate grids, shared repair edits, shared verifier disagreements, and same checkpoint parent. Penalize pairs whose errors are likely to co-occur.

Exact contract

Freeze both candidates before scoring; verify demonstrations exactly; emit only two outputs per input; retain rejected alternatives in trace but never leak them into output count.
